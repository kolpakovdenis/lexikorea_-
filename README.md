⚖️ LexiAudit — корейский юридический и аудиторский глоссарий
Единый глоссарий-тренажёр, объединяющий два проекта: LexiKorea: Правовой практикум (корпоративное право, регистрация, налоги) и AuditLex: Контракты & Аудит (договоры аудита, ответственность, отчётность). Более 300 терминов в 12 тематических колодах — карточки, тест, глоссарий с поиском, диалоги и аудирование.
Возможности
Режим	Описание
🎴 Карточки	Переворачивающиеся карточки KO → RU и RU → KO: перевод, разбор слова, пример из договора с озвучкой. Кнопка «✓ Знаю», избранное ☆, случайная карточка 🎲, свайпы на мобильном.
🎯 Тест	Выбор правильного перевода из 4 вариантов. Счёт ✔/✘ и серия 🔥, автоматическая озвучка правильного ответа. Направление вопросов берётся из переключателя на карточках.
📖 Глоссарий	Полный список терминов с мгновенным поиском (по корейскому, русскому и разбору). Нажмите на строку — раскроется разбор и пример.
💬 Диалоги	40 реплик реального налогового спора (дело о 법인세법): позиция компании, аргументы налоговой, доказательства, выводы суда.
🎧 Аудио	Слушайте слова текущей колоды в трёх стилях озвучки: естественно 🗣️, мягко 🛋️, энергично ⚡.
Плюс: 💬 цитата дня на карточках, светлая/тёмная тема 🌓, прогресс изучения по каждой колоде, избранное и изученное сохраняются в браузере.

Файлы
```

```
Достаточно положить 4 файла в репозиторий с включённым GitHub Pages — сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`. Никакой сборки и зависимостей нет: чистые HTML/CSS/JS.
Как редактировать словарь
Все слова лежат в начале `script.js` между баннерами-комментариями:
```js
const DECKS = { audit: {label:"Аудит и отчётность", icon:"📋", color:"#0ea5e9"}, … };

const GLOSSARY = [
  { ko: "감사조서",                 // корейский термин
    ru: "рабочие документы аудитора", // перевод
    hint: "감사 (аудит) + 조서 (протокол)", // подсказка/разбор (можно пусто)
    exKor: "감사조서는 …",            // пример (необязательно)
    exRus: "Рабочие документы …",     // перевод примера (необязательно)
    deck: "audit" },                  // ключ колоды из DECKS
  …
];
```
Чтобы добавить слово — допишите объект в `GLOSSARY` и укажите существующий ключ `deck`.
Чтобы добавить колоду — добавьте ключ в `DECKS` (иконка + цвет) и используйте его в карточках.
Диалоги — массив `DIALOGUES`, цитаты — `QUOTES` (формат `{kor, rus}`).
Управление
Клавиша	Действие
`←` / `→`	предыдущая / следующая карточка
`Space`	перевернуть карточку
`F`	добавить в избранное ☆
`S`	озвучить текущую сторону
`R`	случайная карточка
На мобильном: свайп по карточке влево/вправо — листание, тап — переворот. Прогресс, избранное, тема и настройки хранятся в `localStorage` (ключи `la_*`), поэтому данные не потеряются между визитами.
История
LexiKorea — правовой практикум (глоссарий по делу о налоге на прибыль, диалоги, аудио).
AuditLex — терминология договоров аудита с морфологическим разбором и примерами из контрактов.
LexiAudit — их объединение: общий формат карточек `{ko, ru, hint, exKor, exRus, deck}`, единый поиск, тест и статистика.
