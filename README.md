⚖️ LexiKorea: Правовой практикум
LexiKorea — это интерактивное веб-приложение (игра-глоссарий) для изучения корейской юридической и финансовой терминологии, специально разработанное для устных и письменных переводчиков, юристов и финансовых специалистов.

Приложение создано на основе реальных документов налоговых судебных разбирательств Республики Корея (система Налогового кодекса Кореи) и охватывает 179 терминов в категориях: Финансы/Налоги, Юриспруденция и Общая лексика.

🚀 Основные возможности
🎴 Интерактивные 3D-карточки: Плавный переворот с использованием глассморфизма. Увеличенный шрифт для комфортного чтения сложных иероглифов.
⚖️ Папка "Избранное": Оригинальная иконка "Пера" позволяет добавлять трудные карточки в отдельную колоду для быстрого повторения.
🤖 AI-контексты: К каждому слову добавлено объяснение того, в каких ситуациях на реальных совещаниях используется этот термин.
💬 Диалоговая практика: Горизонтальная карусель из 40 готовых фраз (по 10 на каждый блок: позиция истца, аргументация налоговой, процедуры, выводы суда).
🎧 Умное аудирование (TTS): Интегрированный синтезатор речи корейского языка с тремя стилями произношения: Естественно, Мягко, Энергично.
🌓 Темная и светлая темы: Дизайн вдохновлен HarmonyOS, с фирменными цветами Huawei.
🛠 Технологии
Приложение написано на чистом (Vanilla) JavaScript, HTML5 и CSS3.

Никаких фреймворков и тяжелых библиотек.
Полностью адаптивный дизайн (Mobile-first).
Локальное сохранение прогресса (LocalStorage).
📁 Структура проекта
Весь код разделен на логические модули для удобства редактирования:

index.html — Каркас приложения.
style.css — Стили, дизайн-система, анимации.
script.js — Логика (состояние, карусели, TTS, избранное).
data.js — База данных слов, фраз и диалогов.

📚 Источник данных
База терминов составлена на основе судебных прецедентов (Спор о признании дебиторской задолженности безнадежным долгом).
